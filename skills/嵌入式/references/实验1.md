# 一、设计思路
本实验通过“STM32CubeMX 生成工程 → Keil 编译生成 hex → Proteus 仿真运行”的完整流程，验证开发环境搭建是否成功。电路采用 LED 低电平点亮（灌电流）接法：电源 POWER（3.3V）经 33Ω 限流电阻 R1 接 LED 正极，LED 负极接 STM32F103C6 的 PA1 引脚。CubeMX 中 PA1 配置为输出模式，默认输出低电平，程序运行后 LED 两端形成压差而导通点亮。
# 二、STM32CubeMX 工程创建与配置
（1）打开 STM32CubeMX 软件，点击 ACCESS TO MCU SELECTOR 按钮，新建 CubeMX 项目。
（2）进入 MCU/MPU Selector 界面，在搜索框中输入芯片型号 STM32F103C6T，在右侧结果列表中选中 STM32F103C6Tx，点击 Start Project 启动项目。
（3）进入 Pinout & Configuration 界面，在 Pinout view 中点击 PA1 引脚，在弹出菜单中选择 GPIO_Output，将其配置为输出模式，配置成功后该引脚变为绿色。
（4）导入固件包：进入固件包管理界面，点击 From Local，选择本机上的固件包 stm32cube_fw_f1_v180.zip，点击打开完成导入，固件包版本为 V1.8.0。
（5）进入 Project Manager → Project 界面进行配置：Project Name 设置为“{后4位}-test1”（学号后 4 位-test1，表示第 1 次实验）；Project Location 选择项目根目录（如桌面下新建的 keil 目录，路径必须为全英文，否则后续会出错）；Toolchain/IDE 选择 MDK-ARM，版本保持默认；取消勾选 Use Default Firmware Location，在 Firmware Relative Path 中选择仓库目录下的 STM32Cube_FW_F1_V1.8.0 固件包。
（6）进入 Code Generator 界面，勾选“Generate peripheral initialization as a pair of '.c/.h' files per peripheral”，然后点击右上角 GENERATE CODE 按钮生成 Keil 项目代码。
（7）代码生成成功后弹出提示框：点击 Open Project 直接用 Keil 打开项目；若没有该按钮，则点击 Open Folder 打开项目目录，确认目录结构正确后，双击 MDK-ARM 目录下的 {后4位}-test1.uvprojx 文件手动打开项目。
# 三、Keil 编译生成 hex 文件
（1）在 Keil 中打开项目后，点击工具栏的 Build 按钮编译项目。若编译失败并提示“找不到 STM32F1 系列芯片型号”，需先双击安装依赖库 Keil.STM32F1xx_DFP.2.2.0.pack，安装过程中一直点击 Next，出现报错窗口点确定即可，安装完成后重新编译。
（2）编译完成后，Build Output 窗口显示“0 Error(s)”，表示编译成功。
（3）检查 MDK-ARM/{后4位}-test1 目录下是否已生成 .hex 文件。若未生成，点击 Options for Target（魔术棒按钮），在 Output 选项卡中勾选 Create HEX File，点击 OK 后重新编译项目。
# 四、Proteus 电路设计与仿真联调
（1）打开 Proteus 软件，点击 New Project 新建项目，设置项目名称为 {后4位}-test1，选择项目保存目录，点击 Next；后续页面保持默认一直点击 Next，最后点击 Finish。
（2）添加元器件，共 3 个：芯片 STM32F103C6、电阻 RES、红色发光二极管 LED-RED。在元器件库中依次搜索以上型号并添加到元器件列表。
（3）在元器件列表中点击选中元器件，然后在右侧网格页面上点击鼠标将其放置到图纸上。
（4）添加电源：先点击左侧 Terminals Mode 按钮，再选择 POWER，在网格页面上点击放置电源终端。
（5）连接电路：POWER 接电阻 R1 一端，R1 另一端接 LED 正极，LED 负极接 STM32 芯片的 PA1 引脚，注意 LED 的正负极方向。双击电阻下方的阻值 10k，在 Edit Part Value 窗口中将其修改为 33。
（6）配置电源路线：点击菜单栏 Design → Configure Power Rails…，在 GND 电源网络中添加 VSSA；在 VCC/VDD 电源网络中添加 VDDA，并将电压修改为 3.3V。
（7）加载程序：双击 STM32 芯片，打开 Edit Component 窗口，在 Program File 中选择 Keil 编译生成的 {后4位}-test1.hex 文件，点击 OK。
（8）点击左下角的运行按钮开始仿真，观察到 LED 被点亮。引脚旁的红色小方块表示高电平，蓝色表示低电平，此时 PA1 为低电平，说明整个开发环境搭建成功、工程创建与仿真联调流程正确。
