# 一、设计思路
GPIO 输入原理：引脚配置为输入模式时，外部电平经施密特触发器整形后存入输入数据寄存器（IDR），程序读取该寄存器即可得到引脚当前电平。本实验将 PA2 配置为上拉输入，内部上拉电阻使按键未按下时 PA2 保持高电平；按键一端接 PA2、另一端接地（GROUND），按下时 PA2 被拉为低电平。
按键消抖：机械按键在按下和松开的瞬间会产生约 5～10ms 的电平抖动，若不处理会被误判为多次按下。程序采用软件延时消抖：检测到 PA2 为低电平后延时 20ms 再次读取，仍为低电平才确认按键按下，然后翻转 LED 状态；接着等待按键松开，再延时 20ms 消除释放抖动。
电路设计：LED 部分与实验一相同，POWER（3.3V）经 33Ω 电阻 R1 接 LED 正极，LED 负极接 PA1，PA1 低电平时 LED 点亮；按钮 BUTTON 一端接 PA2，另一端接 GROUND。
# 二、STM32CubeMX 工程配置
（1）打开 STM32CubeMX，点击 ACCESS TO MCU SELECTOR，搜索并选择芯片 STM32F103C6Tx，点击 Start Project。
（2）在 Pinout & Configuration 界面，将 PA1 引脚设置为输出模式 GPIO_Output，将 PA2 引脚设置为输入模式 GPIO_Input。
（3）在 System Core → GPIO 中配置引脚参数：PA1 的 User Label 设置为 LED；PA2 的 GPIO Pull-up/Pull-down 设置为 Pull-up（上拉），User Label 设置为 Key。
（4）在 Project Manager 界面中，将 Project Name 设置为“{后4位}-test3”（学号后 4 位-test3，表示第 3 次实验），其他设置与实验一相同：Toolchain/IDE 选择 MDK-ARM，固件包选择 STM32Cube_FW_F1_V1.8.0；在 Code Generator 中勾选生成独立的 .c/.h 文件，点击 GENERATE CODE 生成代码，并用 Keil 打开项目。
# 三、Keil 程序编写与编译
（1）在 Keil 的 Project 窗口中，点击 Application/User/Core 目录左边的“+”展开目录，双击 main.c 文件将其打开，并在 main 函数中定义用于保存按键状态的变量 key_val。
（2）找到第 95 行的 while(1) 循环，在循环里面添加如下代码：
```
key_val = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_2);
if(key_val == GPIO_PIN_RESET)
{
    HAL_Delay(20);
    if(HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_2) == GPIO_PIN_RESET)
    {
        HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_1);
        while(HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_2) == GPIO_PIN_RESET);
        HAL_Delay(20);
    }
}
```
其中用到 3 个函数：HAL_GPIO_TogglePin 翻转引脚电平，参数 GPIOA、GPIO_PIN_1 表示翻转 PA1；HAL_GPIO_ReadPin 读取引脚电平，参数 GPIOA、GPIO_PIN_2 表示读取 PA2，返回 GPIO_PIN_RESET 表示低电平（按键按下）；HAL_Delay 为延时函数，参数 20 表示延时 20ms，用于按键消抖。
（3）点击 Build 编译项目，输出窗口显示“0 Error(s)”，编译成功，并在 MDK-ARM/{后4位}-test3 目录下生成 {后4位}-test3.hex 文件（若未生成，在 Options for Target → Output 中勾选 Create HEX File 后重新编译）。
# 四、Proteus 仿真验证
（1）打开 Proteus，新建项目，项目名称为 {后4位}-test3，步骤与实验一相同。
（2）添加元器件 STM32F103C6、RES、LED-RED、按钮 BUTTON，在 Terminals Mode 中添加电源 POWER 和地 GROUND。按 POWER → R1(33Ω) → LED 正极、LED 负极 → PA1 连接 LED 电路；按钮一端接 PA2，另一端接 GROUND。
（3）点击 Design → Configure Power Rails…，在 GND 中添加 VSSA，在 VCC/VDD 中添加 VDDA 并将电压改为 3.3V。
（4）双击 STM32 芯片，在 Program File 中导入 {后4位}-test3.hex 文件，点击 OK。
（5）点击运行按钮开始仿真。初始状态下 PA1 输出低电平，PA2 因上拉处于高电平，LED 点亮；按下按钮并松开，LED 熄灭；再次按下并松开，LED 重新点亮，验证了按键控制 LED 开关及消抖程序正确。
