# 图文工作台文件格式

工作台根目录：`~/图文创作/`，启动：双击 `启动工作台.command`，浏览器打开 http://127.0.0.1:8765

## 目录

```
图文创作/
├─ 启动工作台.command      双击启动
├─ 使用说明.md
├─ 00-素材库/              跨项目复用的素材
│  ├─ 人物母图/            锁脸用的身份参考图
│  ├─ 风格参考/            风格、构图、配色参考
│  └─ 截图/                教程截图
├─ 01-项目/                一篇文章 = 一个项目
│  └─ 2026-10-26-项目名/
│     ├─ 项目.json         标题、状态、标签、模型参数
│     ├─ 文章.md           X 长文正文（工作台一键复制）
│     ├─ 发布包.md         标题备选、发布文案、首评、短推
│     ├─ 提示词/           本项目用的提示词 .txt
│     ├─ 生成/             API 每次生成的原图 + 同名 .json（提示词和参数）
│     ├─ 成品图/           挑出来要用的图
│     ├─ 配图/             文章里按顺序插的图 01.jpg 02.jpg …
│     ├─ 封面/             5:2 封面
│     └─ 资料/             笔记、来源、草稿
├─ 02-提示词库/            通用模板，可跨项目复用
├─ 03-技能Skill/           技能调用卡和规范
├─ 04-已发布归档/          发布后把项目整个移进来
└─ 工作台/                 程序（server.py、index.html、.env 密钥）
```

## 项目.json

```json
{
  "title": "项目名",
  "status": "草稿",          // 草稿 / 生图中 / 待发布 / 已发布
  "tags": ["生图教程"],
  "created": "2026-10-26",
  "published_url": "",
  "gen": { "model": "", "size": "1536x2730", "refs": ["00-素材库/人物母图/00-母图.jpg"] }
}
```

## 文章.md

```markdown
---
title: 同一张脸 六种身材 我是怎么用一张母图做出来的
cover: 封面/cover.jpg
---
开头段落，前 60 字单独成立……

![配图1：六种身材正面对比拼图](配图/01.jpg)

## 小标题（编辑器里的 Heading）

段落里可以有 **加粗的关键句**。

### 更小的标题（编辑器里的 Subheading）

1. 有序列表
2. 第二步

- 无序列表

> 引用块，适合放一段完整提示词或官方原话

【配图2：还没做好的图先这样占位】
```

规则：
- front matter 里的 title 是文章标题，不会进入复制的正文
- `##` → X 编辑器 Heading，`###` → Subheading
- 段落之间空一行（Markdown 分段），工作台复制时会合并成编辑器的单个段落，不会出现空段
- 图片用 `![配图N：说明](配图/xx.jpg)`，文件放项目的 配图/ 文件夹；还没有图就用 【配图N：说明】
- 复制正文时，图片位置会变成 【配图N：说明】 占位；工作台里每张图旁边有 复制图片 按钮，粘贴到编辑器对应位置后删掉占位字
- 不要用代码块、表格（X 编辑器不支持），提示词用 `>` 引用块
- 链接写成普通文字或 Markdown 链接都行，但来源链接放发布包的首评

## 发布包.md

每个 `###` 是一张可复制卡片，工作台会显示 X 字符数（中文算 2，上限 280；发布文案上限 256）。

```markdown
## 标题备选
### 标题 1（推荐）
……
### 标题 2
……

## 发布文案
### 文案 1（推荐）
……

## 首评
### 首评
来源链接、完整提示词……

## 预告推
### 预告
……

## 引流短推
### 短推 1
……

## 待实测
- 【待实测：……】
```
