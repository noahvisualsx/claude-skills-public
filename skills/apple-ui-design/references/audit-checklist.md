# 界面审查清单

审查一个现有界面时，按这张表逐项过，输出「问题 → 依据（HIG 页面）→ 改法 → 严重度」。
严重度：**P0** 功能或可读性受损 / 违反辅助功能底线；**P1** 明显不符合平台惯例；**P2** 细节打磨。

先收集事实再下结论：
1. `python3 scripts/audit_swiftui.py <源码目录>` 得到机器能找到的问题（它是启发式的，每条都回代码确认）；
2. 读视图代码；截图（浅 / 深 / 深 + 高对比 / 降低透明度各一张，办法见 `swiftui-macos.md` §4）；
3. 用 `contrast.py` 实测品牌色、次级文字、按钮文字的对比度。

## A. 结构与层级
- [ ] 功能层（导航、控件）和内容层分得清吗？内容层有没有上玻璃？（P1）
- [ ] 玻璃上是否又叠了玻璃？（P1）
- [ ] 同屏自定义玻璃元素是否只限最重要的一两个？多个玻璃是否放进 `GlassEffectContainer`？（P2，性能 P1）
- [ ] 工具栏 / 侧栏 / 弹出框 / Sheet 上有没有自定义背景盖住系统效果？（P1）
- [ ] 内容滚到浮动控件下面时，用的是滚动边缘效果而不是半透明垫片？（P2）
- [ ] 最重要的内容在上方前侧？层级是否一眼可辨？（P1）
- [ ] 关键操作没有放在窗口 / 侧栏底部？（macOS P1）

## B. 颜色
- [ ] 文字对比度：≤17pt ≥ 4.5:1，≥18pt 或粗体 ≥ 3:1（P0）
- [ ] 每个自定义颜色有浅 / 深 / 高对比变体？（P1）
- [ ] 有没有写死系统色的十六进制值？（P2）
- [ ] 颜色是否是唯一的信息载体（状态只靠红绿）？（P0）
- [ ] 同一种颜色是否表达了不同含义？（P1）
- [ ] 醒目 / 染色按钮是否 ≤ 2 个、主操作只有一个？（P1）
- [ ] 跟随系统外观了吗？有没有 app 内的外观开关覆盖系统？（P1）
- [ ] 选中 / 强调是否用了用户的系统强调色（macOS `controlAccentColor`）？（P2）

## C. 字体
- [ ] 最小字号：macOS ≥ 10pt、iOS ≥ 11pt（P0）
- [ ] 小字是否用了 Light / Thin / Ultralight？（P1）
- [ ] 是否优先用文本样式（`.body` `.caption`…）而不是写死字号？（P2）
- [ ] 字体家族 ≤ 2 个？数字列是否用等宽数字？（P2）
- [ ] 大字号 / 粗体文本设置下布局是否崩、是否截断关键文字？（P1）

## D. 控件与交互
- [ ] 控件尺寸：macOS ≥ 20×20（默认 28×28）、iOS ≥ 28×28（默认 44×44）；点击区 ≥ 44×44（P0/P1）
- [ ] 自定义控件有按下态、悬停态（macOS）、禁用态、焦点环？（P1）
- [ ] 纯图标按钮有 `accessibilityLabel` 和 `.help` tooltip？（P0 / P2）
- [ ] 图标用 SF Symbols 且符合标准图标表？工具栏里没有带圈的符号？（P2）
- [ ] 破坏性按钮没有 primary 角色、有确认或可撤销？（P0）
- [ ] 打开新窗口 / 需要进一步输入的按钮和菜单项末尾有「…」？（P2）
- [ ] 右键菜单里的操作在主界面也能找到？不可用项在右键菜单隐藏、在主菜单置灰？（P1）
- [ ] 同一组菜单项的图标是全有或全无？（P2）
- [ ] 弹出框：一次一个、不嵌套、不用来显示警告、点外面关闭时保存了修改？（P1）
- [ ] 开关（switch）只在列表 / 表单行里；macOS 单个开 / 关设置优先 checkbox？（P2）
- [ ] 全键盘可操作：Tab 能到达、Esc 能关闭、回车触发主操作、快捷键没有抢系统的？（P1）

## E. 动效与时间
- [ ] 高频操作上没有多余动画？动画可以被打断？（P2）
- [ ] 「减少动态效果」开启时去掉了装饰性形变 / 弹跳？（P1）
- [ ] 需要阅读的信息没有只放在定时自动消失的浮层里？悬停时不会自动收起？（P1）
- [ ] 「降低透明度」开启时，自定义半透明层变实了？（P1）

## F. 文案与反馈
- [ ] 按钮是动词短语，没有「确定 / OK」之类空话（纯告知弹窗除外）？（P2）
- [ ] 错误信息说清发生了什么 + 怎么办，并提供修复入口？（P1）
- [ ] 空状态给了下一步？（P2）
- [ ] 加载状态尽快显示内容、说明在做什么？（P2）
- [ ] 标题 < 15 字符、不用 app 名当窗口标题？（P2）
- [ ] 用了 AI 的地方有标识、有重试 / 编辑、失败时指导用户怎么改？（P1）

## G. 平台与兼容
- [ ] 最低系统版本以下的退化路径存在且可用（`if #available`）？（P0）
- [ ] 设置放在标准「设置」窗口（⌘,），改动即时生效？（P2）
- [ ] 窗口可调整大小，内容自适应；最大 / 最小尺寸都看过？（P1）
- [ ] 右到左语言下用的是 leading / trailing？（P2）

## H. 简体中文（见 `chinese-ui.md`）
- [ ] 引号用 “”，不用「」；省略号用 …，不用 ...（P2）
- [ ] 中文和英文 / 数字之间没有手动空格（系统自动留间距；网址两边例外，留空格方便选中）（P2）
- [ ] 中文句子用全角标点；完整句子结尾有 。，按钮 / 菜单没有句号（P2）
- [ ] 用词和 Apple 一致：拷贝、共享、重新命名、好、以后、进一步了解、边栏（P2）
- [ ] 人称用「你」；出错文案先说结果再说办法（P2）
- [ ] 宋体（`.serif`）只用于 17pt 以上标题；没有给中文加字距或斜体（P2）

## I. 稳定性（SwiftUI macOS，见 `swiftui-macos.md` §1）
- [ ] 窗口工具栏项不随页面增删；`.inspector` 不按页面开关；`.searchable` 只挂一处（P0）
- [ ] 分栏各列的最小 / 最大尺寸是常量（P0）
- [ ] 自动切页压力测试连续跑 5 次以上无崩溃（P0）
- [ ] 主线程没有读大文件 / 解析 / 排版这类重活（P1）

## J. AI 功能（见 `generative-ai.md` §6）

## 输出格式建议

```
### P0
1. 【对比度不足】剪贴板行的时间戳（Palette.t4 on raised）实测 3.9:1 < 4.5:1
   依据：HIG › Accessibility › Vision；改法：t4 提到 0.85 白 或 字号改 ≥18pt
...
### 已符合的点（简短列出，让人知道哪些不用动）
### 未验证（说明原因）
```
