# 翻车点速查表

出图后按这张表逐项对照。左边是症状，中间是真正的原因，右边是补进提示词的句子。

---

## A. 脸

| 症状 | 根因 | 补救 |
|---|---|---|
| 脸变成了服装参考图里模特的脸 | C 图带脸，视觉信息压过文字 | 裁头 / 遮脸 / 走两步法。写多少「不要采纳 C 的脸」都无效 |
| 脸整体变圆、变幼、眼睛变大 | 妆容段落描述过多，给了模型重绘许可 | 压缩妆容段，加「不要放大眼睛，不要削尖下巴，不要磨平颧骨，不要幼态娃娃脸」 |
| 颧骨被磨平、失去锋利感 | 默认美化倾向 | 加「保留皮肤纹理与真实骨感，不磨皮，不磨平颧骨」，并在铁律里点明 A 脸的特质 |
| 多张之间脸逐张漂移 | 无一致性约束 | 加「N 张的脸必须是同一个人、同一套骨相，不允许逐张漂移」；把第一张作为额外参考图传入 |
| 眼线变淡、眼型变柔 | 妆容被「重新设计」 | 眼妆只写「怎么画」不写「画成什么风格」；把眼线形状写成硬指标 |

## B. 服装

| 症状 | 根因 | 补救 |
|---|---|---|
| 衣服被重新设计成常见款 | 结构特殊，纯文字锁不住 | 加服装参考图 C。文字再细也不如一张图 |
| 复杂结构被简化（如立领+镂空系带变成普通一字肩） | 模型只认得常见款 | 把结构拆成 ①②③④ 逐条描述，并写「不是普通的 XX」 |
| 刺绣 / 印花被放大 | 默认往装饰性强的方向画 | 加「图案极小，每个不超过 3 厘米」 |
| 纱裙层数变少 | — | 加「三到四层蓬松网纱，层次分明」 |
| 过膝袜画成裤袜 | — | 加「袜口在大腿中部，袜口与裙摆之间露出一小段皮肤」 |
| 交领画成左衽 | 古装常见硬伤 | 加「交领必须右衽：穿着者的左襟压在右襟之上，正面看衣领呈小写 y 字形。严禁左衽」 |
| 衣服变成仙侠手游时装 / 影楼古装 | 训练数据里这类图最多 | 禁止清单里明确列出；服装参考图用实物平铺图 |
| 领口被拉低成深 V | 默认往性感方向滑 | 加「胸口保持含蓄克制，不是现代低胸礼服，不要露胸沟」 |
| 颜色跑偏（燕麦色变灰色） | — | 单独写一行颜色修正：「臂弯上的外套为浅燕麦色／卡其米色，不是灰色」 |

## C. 比例与镜头

| 症状 | 根因 | 补救 |
|---|---|---|
| **人显矮、腿短** | ①机位太高 ②腰线太低 ③高髻加大了头部单元 | 三条一起补，见下方「显矮三件套」 |
| 全身照头大身小 | 广角贴近拍 | 加「使用等效 85mm 中长焦拉开距离，不要广角贴近拍」 |
| 全身照像证件照 | 双脚平行正面直立 | 加「一脚略前一脚略后，重心落在后腿，前腿膝盖微微放松」 |
| 景别不对（要半身给了全身） | 取景范围没写死 | 写明「画面下边缘裁切在大腿中部，不要露出膝盖和小腿」 |
| 分镜指令没落地，多张姿势雷同 | 分镜段落在提示词末尾被稀释 | 把分镜提到脸部铁律之后；或拆成多次单独生成 |

### 显矮三件套

```
相机必须放低到人物膝盖高度做低机位，远景水平线要落在人物膝盖附近，
绝对不要落在腰部或胸口。使用等效 85mm 中长焦拉开距离拍摄。
腰封位置必须在肋骨下缘，明显高于自然腰线，绝对不要压在肚脐或胯部。
头身比不低于 1:7.5。高髻与发冠属于发型，不计入头部长度。
```

**诊断口诀：**背景水平线落在胸口 = 相机太高；落在膝盖 = 正确。

## D. 光线与影调

| 症状 | 根因 | 补救 |
|---|---|---|
| 人像抠图贴上去的 | 人物光与环境光不匹配 | 补光线一致性硬指标那一段 |
| 人物整个在阴影里、画面发平 | 没写光位 | 写明光从哪个方向来、受光面在哪、明暗对比强度 |
| 白色衣服过曝成一片死白 | — | 加「白色部分不能过曝成一片死白，要保留面料层次与褶皱细节」 |
| 出现电影橙青调 / 金色滤镜 | 默认审美倾向 | 禁止清单里列出 |
| 仙气烟雾、光粒子、发光皮肤 | 「古风」触发的默认特效 | 禁止清单里列出 |

## E. 手

| 症状 | 补救 |
|---|---|
| 手指数量错误、粘连 | 「手必须结构完全正确，五指清点无误，不多指不断指不粘连」 |
| 手被袖子吞掉、只剩一只手 | 「双手都必须清晰可见、结构正确，不要被袖子完全吞没，不要藏手」 |
| 手掌过大 | 「手与脸的比例正常，手不要画得过大」 |

## F. 杂项

| 症状 | 补救 |
|---|---|
| 画面里出现水印、播放按钮、手机状态栏 | 参考图先裁掉这些区域；禁止清单里写「不要出现水印、播放按钮、状态栏等界面元素」 |
| 参考图的水印被当成图案画进衣服 | 一定要裁掉水印再传 |
| 出成了四宫格 | 「生成 N 张彼此独立存在的单图文件，不要四宫格，不要拼接」 |
| 一次改多张时某张几乎没变 | 把那张单独拎出来重跑 |

## G. 题材专属禁止清单

**古风 / 汉服**
```
左衽、大红金宫装、巨大凤冠、过量金饰、影楼古装、塑料假发、
仙侠特效、光粒子、发光皮肤、漂浮无重力的衣袖、
明清点翠凤钗（若为汉制）、唐代花钿（若非唐制）
```

**现代街拍**
```
影视海报感、CG感、棚拍布光、大面积柔焦、
电影橙青调、过度磨皮、发光皮肤
```

**妆造特写**
```
韩式大卧蚕、超长假睫毛、太阳花睫毛、现代硬朗浓眉、
过强鼻影、把唇画大、重度磨皮
```
