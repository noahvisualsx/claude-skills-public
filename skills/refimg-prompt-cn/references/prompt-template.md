# 提示词模板

## 一、单张生成 · 完整骨架

把方括号里的内容替换成具体描述。段落顺序不要调整。

```
【参考图说明】
参考图 A = 人物身份母图，唯一的脸部来源（骨相基准）。
参考图 B = 场景母图，唯一的背景来源。
参考图 C = 服装／妆造母图，唯一的服装、发型、头饰与妆容来源。1:1 复制这套造型的全部结构与细节。
C 图中模特的脸、五官、身材比例、动作、背景、灯光、滤镜、以及截图的状态栏、进度条、播放按钮等一切界面元素，全部不采纳。

【优先级】
脸 → 只看 A；背景 → 只看 B；衣服与妆造 → 只看 C。三者互不干扰。

【脸部铁律】
脸是全图唯一不可改动的元素。妆容与造型只能覆盖在参考图 A 原有的五官结构之上，
不允许改变脸型宽窄、下颌线、下巴长度与尖度、眼睛形状与大小、眼距、眉眼间距、
鼻梁高度、鼻翼宽度、嘴巴大小、上下唇比例、人中长度、年龄感。
不要放大眼睛，不要削尖下巴，不要磨平颧骨，不要幼态娃娃脸。
[补一句 A 脸的特质，例如：参考图 A 的脸偏锋利有骨感，必须保留这种锋利。]
造型与脸冲突时，一律以脸为准。

【身材比例硬指标】
腰封／腰线位于肋骨下缘的高腰位置，不要压在肚脐或胯部。
人物头身比不低于 1:7.5。高髻与发冠属于发型，不计入头部长度。
不要俯拍造成的腿部压缩，不要广角造成的近大远小畸变。

【姿势与构图】
[身体朝向、头部角度、双手各自在做什么、表情与眼神、取景范围、
 相机高度与俯仰、人物在画面中的占比与位置、景深]

【服装（以参考图 C 为准）】
[色系 → 上身结构 → 袖型 → 下装 → 腰部 → 配件 → 面料真实感]

【妆发（以参考图 C 为准）】
[底妆 → 眉 → 眼 → 唇 → 面色 → 发型 → 头饰 → 耳饰]

【场景与光线（以参考图 B 为准）】
[背景元素逐项列出]
可以改变人物站位、拍摄方向和距离，但不能重新想象、不能增删场景物件。

光线一致性是硬指标：人物必须自然接受现场的环境光与色温，
绝不能出现人物是暖黄棚拍光、背景是冷色户外光的抠图感。
头发边缘、半透明面料、毛绒与饰品都要真实受现场光影响。

【影调】
[拍摄器材感 → 色调倾向 → 饱和度 → 对比度 → 颗粒]
真实照片，非插画非CG。

【禁止】
[基础清单 + 本次题材的专属禁止项]
```

## 二、一次出多张 · 分镜前置版

在骨架的【脸部铁律】之后、【服装】之前插入：

```
【输出要求】
生成 N 张彼此独立存在的竖构图单图文件。
不要四宫格，不要拼接，不要上下或左右拼图，不要把多个分镜放进同一张画布。
N 张是同一个人、同一天、同一场景、同一套妆造。
发型形状、头饰的种类数量与位置、妆容浓度、服装细节、腰带高度，N 张必须完全一致，
只允许因视角产生正常变化。

【分镜】
第一张·[景别名称]：[身体朝向 + 手部动作 + 表情眼神 + 取景范围 + 相机高度]
第二张·[景别名称]：[同上]
第三张·[景别名称]：[同上]
第四张·[景别名称]：[同上]
```

**四张分镜的经典配置**

| 顺序 | 景别 | 作用 | 关键指令 |
|---|---|---|---|
| 1 | 中近景 | 展示脸与妆造细节 | 相机与脸齐平，人物占画面 85% |
| 2 | 坐姿中景 | 展示布料铺开的层次 | 相机略低于胸口，双手都要可见 |
| 3 | 全身 | 展示整套衣服与比例 | **膝盖高度低机位 + 85mm 中长焦** |
| 4 | 侧身回眸 | 情绪与侧脸线条 | 肩线偏离镜头，头转回 |

## 三、二次修改指令

### 3.1 只换脸（两步法的第二步）

```
参考图 1、2、3、4 = 待修改的照片。
参考图 5 = 正确的脸，唯一的脸部来源。

【任务】
对参考图 1、2、3、4 分别做一次脸部替换，输出 4 张彼此独立的修改后照片，与输入一一对应。
不要合并，不要四宫格，不要拼接，每张单独输出。

【修改内容】
只修改每张照片中人物的脸部五官，把脸完整替换成参考图 5 这个人的脸：
脸型轮廓、脸部宽窄、下颌线、下巴长度与尖度、眼睛的真实形状与大小、眼距、眉眼位置关系、
鼻梁高度、鼻型、鼻翼宽度、嘴巴大小、上下唇比例、人中长度、年龄感，全部以参考图 5 为准。
四张输出的脸必须是同一个人、同一套骨相，不允许逐张漂移。

【必须保持不变的部分】
除了五官本身，每张照片的其余部分必须像素级保持不变：
[逐项列出该造型的所有细节：头饰、发型、妆容装饰、服装、手部、背景、光线、色调、构图]
每张照片原本的头部角度、脸的朝向、俯仰角度、表情必须原样保留，只换五官本身。

【禁止】
放大眼睛、削尖下巴、磨平颧骨、重新美化、幼态娃娃脸、过度磨皮、
改变妆容浓度或位置、改变头部角度、改变表情、改变构图或裁切、
输出数量不足、四宫格与任何形式的拼接。
```

### 3.2 只改脸（单张，轻修）

```
脸部与参考图 A 存在偏差。请只修改脸部，把五官完全替换回参考图 A 的样子：
保持同样的眼距、眼型上扬弧度、鼻梁高度、人中长度和唇形厚度，
不要缩小脸、不要放大眼睛、不要改变下颌角度，其余画面元素全部保持不变。
```

### 3.3 只改镜头与比例

```
【镜头与光线修正】
相机高度与人物胸口齐平，平视拍摄，绝对不要俯视。
镜头贴近人物，人物占据画面高度的 90% 以上，头顶几乎顶到画面上边缘，
画面下边缘裁切在大腿中部，不要露出膝盖和小腿，不要拍全身。
其余内容全部保持不变。
```

### 3.4 只改局部服装

```
只修改上衣，其余全部不变。上衣改成 [具体结构描述]。
不要画成 [模型默认会画成的常见款式]。
```

## 四、氛围感创作（只有人物图）

```
【参考图说明】
参考图 A = 人物身份母图，唯一的脸部来源。只提取脸与骨相，其余一律不采纳。
本次没有场景与服装参考图，场景、服装、光线、姿势全部按下面的描述执行。

【脸部铁律】
脸是全图唯一不可改动的元素。妆容、造型、光线与风格化处理只能覆盖在参考图 A
原有的五官结构之上，不允许改变脸型宽窄、下颌线、下巴长度与尖度、眼睛形状与大小、
眼距、眉眼间距、鼻梁高度、鼻翼宽度、嘴巴大小、上下唇比例、人中长度、年龄感。
不要放大眼睛，不要削尖下巴，不要磨平颧骨，不要幼态娃娃脸。
画面中的脸必须来自参考图 A，不允许因为造型、光线或风格化而重新设计五官。
N 张的脸必须是同一个人、同一套骨相，不允许逐张漂移。

【输出要求】
生成 N 张彼此独立存在的竖构图单图文件。
不要四宫格，不要拼接，不要把多个分镜放进同一张画布。
N 张是同一个人、同一天、同一地点、同一套服装与妆容，只有景别、姿势与表情不同。

【分镜】
第一张·[景别]：[身体朝向 + 具体在做的动作 + 视线去向 + 取景范围 + 相机高度]
第二张·[景别]：[同上]

【光线】
[从配方库整段复制]

【场景】
[从配方库整段复制，再补 2–3 个具体的环境物件]

【前景遮挡】
[树叶／纱帘／花枝／玻璃／栏杆] 在画面 [位置] 横穿而过，处于虚焦状态，
在人物与镜头之间形成一层，制造空间层次。

【服装】
[材质 + 廓形 + 颜色 + 一个具体细节。跟着配方的色调走]

【妆容】
[只写怎么画在这张脸上：底妆质感、眉、眼、唇。不要写「精致的五官」这类形容]

【色调】
[从配方库复制]

【影调】
真实相机拍摄的质感，保留细微噪点与镜头的自然缺陷，
不要过度锐化，不要重度磨皮，不要发光皮肤，不要AI感的完美。
不要电影橙青、不要仙气烟雾、不要光粒子。
竖构图，真实照片，非插画非CG。

【禁止】
正对镜头的标准微笑、大头照式构图、平光、
AI塑料脸、放大眼睛、幼态娃娃脸、磨平颧骨、过度磨皮、发光皮肤、
过度锐化、HDR感、影楼布光、贴纸感、
错误手指、藏手断手、水印与界面元素、四宫格与任何形式的拼图。
```

**关键提醒**：这个模式下不要在提示词里出现任何对脸的正面形容词（「精致」「美丽」「清纯」「高级脸」）。
只有一张人脸参考时模型的创作自由全会用在脸上，任何褒义形容词都是重画许可。

## 五、场景替换（换背景）

```
【参考图说明】
参考图 1 = 待修改的照片。人物、妆容、发型、头饰、服装、姿势、手持物、构图裁切，全部以这张为准。
参考图 2 = 新的背景来源。只提取空间结构、景物元素与现场光环境。
参考图 2 中不含人物，不要从中提取任何人物信息。

【任务】
把参考图 1 中的人物，原样放进参考图 2 的场景里，重新拍摄这张照片。
换的是背景与光线，不是人。

【必须保持不变（以参考图 1 为准）】
脸：脸型轮廓、脸部宽窄、下颌线、下巴长度与尖度、眼睛形状与大小、眼距、眉眼位置关系、
鼻梁高度、鼻型、鼻翼宽度、嘴巴大小、上下唇比例、人中长度、年龄感，全部不变。
不要放大眼睛，不要削尖下巴，不要磨平颧骨，不要重新美化。
妆容：[逐项列出] 的浓度与位置一律不变。
发型与头饰：[逐项列出] 全部原样保留，不增不减。
服装：[逐项列出] 全部不变。
姿势与手持物：身体朝向、头部角度、手的位置与手指姿态、[手持物] 全部不变。
构图：人物在画面中的位置、大小、裁切范围保持一致。

【新的背景（以参考图 2 为准）】
[从前景到远景逐层描述：前景 → 中景 → 远景 → 画面上方 → 整体照度与色调]

【光线重打（关键）】
这是从 [原光线条件] 换到 [新光线条件]，光线必须整体重做，不能保留原图的光。
人物由 [新的主光来源、方向、柔硬程度] 照亮，[受光面的亮度与阴影描述]。
人物边缘——发丝、饰品、半透明衣料的边缘——必须自然接受背景的 [环境光色温] 与 [反射光],
产生细微的轮廓光和环境色沾染。
绝对不能出现人物是 [原光线]、背景是 [新光线] 的抠图感。
背景保持 [欠曝/正常] 的影调，不要为了看清而整体提亮。

【影调】
[拍摄条件 → 暗部处理 → 色调 → 景深]
真实照片，非插画非CG。

【禁止】
改变脸部五官、改变妆容浓度、增减头饰、改变发髻形状、改变服装细节、
改变姿势或手持物、改变构图裁切、
保留原图的 [原背景标志性元素]、背景出现 [原光线条件]、
人物与背景光线不匹配的抠图感、背景整体提亮失去 [原本的氛围]、
AI塑料脸、放大眼睛、过度磨皮、错误手指、水印与界面元素、拼图。
```

**追加修正句**

人物太亮、浮在背景上：
```
降低人物的补光强度，让脸部亮度只比环境高一到两档，
肩膀外侧与手臂边缘允许落入暗部，与背景的暗调自然衔接。
```

## 六、参考图配置速查

| 需求 | A | B | C | 备注 |
|---|---|---|---|---|
| 换背景 | ✓ | ✓ | — | 服装写在文字里 |
| 换衣服 | ✓ | — | ✓ | C 必须裁头 |
| 换衣服 + 换背景 | ✓ | ✓ | ✓ | 标准三图配置 |
| 复刻某张图的姿势 | ✓ | 姿势图 | ✓ | B 改为姿势/光线来源，明确写「只取姿势与光线」 |
| 复杂妆造（头饰在头上） | ✓ | ✓ | ✓ | 走两步法，或用遮脸版 C |
| 氛围感创作 | ✓ | — | — | 场景服装全由你设计，见第四节 |
| 提取干净背景板 | — | 原图 | — | 移除人物，补全遮挡，机位光线不变 |

**服装参考图的来源优先级**

1. 淘宝汉服店铺**平铺图** — 无脸、无水印、打光均匀、细节清楚
2. 店铺模特图 — 看上身效果与布料垂坠，需裁头
3. 抖音 / 小红书截图 — 画质差、有水印、有脸，最后选择

理想组合：平铺图 2 张定款式 + 上身图 1–2 张定穿法。
水印一定要裁掉，模型会把水印当成图案画进衣服里。
