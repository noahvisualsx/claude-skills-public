# 氛围感配方库

用于「只有人物图，其余全靠设计」的场景。每个配方是一组已经验证过能互相咬合的光线 + 环境 + 色调 + 情绪。
直接整段填进提示词的对应位置，不要混搭两个配方的光线。

---

## 氛围感是怎么来的

按重要性排序，前三条决定成败，后面是加分项。

**1. 光，永远是第一位。**场景可以平平无奇，光对了就成立；场景再好，平光一打就变成游客照。每个配方的核心都是光。

**2. 不要正脸大头照。**侧脸、垂眸、回眸、背身转头、被遮挡的脸——不完全交代，观众才会想看。正对镜头微笑是氛围感的反面。

**3. 前景遮挡。**让树叶、纱帘、花枝、玻璃、栏杆、人群的虚影横穿画面，制造层次与偷窥感。这一条几乎是「像摄影作品」和「像自拍」的分界线。

**4. 环境要有呼吸。**人物不必占满画面。留白、大面积的暗部、空旷的背景，都会让画面安静下来。

**5. 一张图只有一个色温倾向。**冷就冷到底，暖就暖到底，冷暖对撞只在霓虹这类配方里才成立。

**6. 保留不完美。**轻微噪点、镜头光晕、边缘失焦、手持的轻微倾斜。太干净就假了。

**7. 让她在做一件具体的事。**等人、回头、拨开树枝、拉上窗帘、低头看手里的东西。「在做事」比「在摆拍」高一个级别。

## 配方

### R01 · 逆光黄昏

```
【光线】日落前半小时的低角度阳光从人物正后方射入，形成强烈逆光。
发丝被完整勾出金色轮廓光，肩线与手臂边缘发亮，脸部处于柔和的阴影中靠环境反射光照亮。
镜头轻微朝向光源，画面右上角有自然的橙金色光晕与轻微眩光。天空过曝发白。
【场景】开阔的河堤／草坡／麦田，视野空旷，远处地平线低。
【色调】暖金色为主，暗部偏青，整体饱和度中等偏低。
【情绪】安静、恍惚、被时间照着。
【构图】人物偏画面一侧，大面积留给天空与光。中景或全景。
【服装建议】浅色、轻薄、能透光的面料。
```

### R02 · 窗边晨光

```
【光线】清晨的侧窗光从画面一侧射入，被薄纱窗帘打散成柔和的漫射光。
受光面明亮通透，背光面自然落入柔和的暗部，明暗交界柔和无硬边。
空气中可见细微的浮尘在光柱里漂浮。
【场景】室内窗边，木质窗框、白墙、薄纱窗帘、简单的家具轮廓。
【色调】暖白，低饱和，接近黑白但保留一点肤色的暖。
【情绪】清醒、私密、刚睡醒的松弛。
【构图】人物贴近窗，背景大面积留白。中近景或特写。
【服装建议】家居感、棉麻、白色或米色。
```

### R03 · 雨夜霓虹

```
【光线】夜晚，主光来自街边招牌与霓虹灯的彩色光，从侧后方打在人物身上。
湿漉漉的地面把灯光反射成大片模糊的色块。
脸部由一侧的暖色招牌光照亮，另一侧落入青蓝色的暗部，形成冷暖分割。
【场景】雨后的街道，湿地面、积水、模糊的招牌与车灯、行人的虚影。
【色调】青蓝打底，红橙做点缀，冷暖强烈对撞。高对比。
【情绪】疏离、都市、一个人。
【构图】前景可有虚化的雨丝或玻璃雨珠。人物占比不大，环境占主导。中景。
【服装建议】深色、廓形硬朗、有反光材质更好。
```

### R04 · 深夜车内

```
【光线】车内几乎无光，人物由窗外掠过的路灯与对向车灯断续照亮，
光在脸上快速流动，忽明忽暗。仪表盘的微光在下颌处形成一点冷调补光。
【场景】副驾或后座，车窗玻璃上有雨痕或呵气，窗外是拉长的光带。
【色调】深青蓝为主，路灯的暖橙做点缀，大面积暗部。
【情绪】倦怠、失神、在路上。
【构图】隔着车窗或从侧后方拍，脸部部分被暗部吞没。近景。
【服装建议】深色，露出一点颈线。
```

### R05 · 老宅顶光

```
【光线】光从头顶的天井、瓦缝或高窗垂直落下，在地面形成一块明亮的光斑。
人物站在光斑边缘，头顶与肩膀受光，眼窝与下颌落入阴影。
周围大面积欠曝，暗部深沉。空气中有可见的尘埃。
【场景】老宅、祠堂、木构建筑内部，青砖地、木柱、旧家具的剪影。
【色调】暖褐与墨色，低饱和，高对比。
【情绪】沉、旧、有重量。
【构图】人物很小，建筑的暗部占据画面大部分。中景或全景。
【服装建议】传统形制、深色或素色、有重量的面料。
```

### R06 · 海边阴天

```
【光线】阴天的全漫射光，没有方向，没有阴影，整体高调发灰。
天与海几乎连成一片灰白，人物是画面里唯一的深色。
【场景】海边、堤岸、沙滩，风大，视野极空。
【色调】灰蓝与灰白，极低饱和，低对比，接近单色。
【情绪】空、冷、被风吹着。
【构图】大量留白，人物偏小偏一侧。头发和衣物被风吹起。全景或中景。
【服装建议】素色、轻薄、会被风带起来的面料。
```

### R07 · 林间漫射

```
【光线】阳光被树冠层层过滤，落在人物身上形成斑驳跳动的光点。
整体是柔和的绿调环境光，脸部有零星的亮斑。空气微微发湿。
【场景】树林、竹林、庭院深处的绿植丛，枝叶茂密，层次深。
【色调】深绿与墨绿为主，皮肤在绿调环境里显得冷白。
【情绪】幽、静、藏起来。
【构图】必须有前景枝叶遮挡，人物半掩在绿中。中近景。
【服装建议】白色或浅色，在深绿里形成对比。
```

### R08 · 烛光夜室

```
【光线】唯一光源是一到两支蜡烛或一盏暖黄小灯，位置低于人物脸部，从下前方照上来。
受光面暖橙且明亮，衰减极快，一步之外就是纯黑。
【场景】夜晚室内，桌面、器物、帷幔的暗部轮廓。
【色调】暖橙与深褐，暗部纯黑，高对比。
【情绪】私密、危险、离得很近。
【构图】特写或近景，脸部半明半暗，背景全暗。
【服装建议】质感强的面料，暗色或与肤色接近的色。
```

### R09 · 雪日高调

```
【光线】雪天的漫射光，从雪地反射上来的光把下颌与眼下也照亮，
人物几乎没有阴影，皮肤通透。整体过曝半档。
【场景】雪地、白墙、雾，视野被雪与雾切断，背景几乎是空的。
【色调】冷白与浅灰，极低饱和，低对比。
【情绪】干净、冷、被抹掉了背景。
【构图】极简，大面积留白，人物是唯一的信息。中近景。
【服装建议】深色，或纯白到与背景融为一体。
```

### R10 · 玻璃倒影

```
【光线】隔着一层玻璃拍摄。玻璃反射着对面的景物与光源，
人物的脸与倒影叠在一起，部分被反射的光斑覆盖。
【场景】咖啡馆窗外、地铁车厢、橱窗、雨后的车窗。
【色调】跟随环境，但因为玻璃的存在整体偏灰、偏低对比。
【情绪】隔着一层、看不清、被观察。
【构图】人物在玻璃后，倒影在玻璃前，两层信息叠加。中近景。
【服装建议】不重要，重点在光与反射。
```

## 怎么选配方

按人物的气质选，不要按「好不好看」选。

| 人物气质 | 推荐配方 |
|---|---|
| 冷艳、疏离、无机质 | R03 雨夜霓虹、R04 深夜车内、R09 雪日高调、R10 玻璃倒影 |
| 柔软、清透、少女感 | R01 逆光黄昏、R02 窗边晨光、R07 林间漫射 |
| 沉静、有故事、成熟 | R05 老宅顶光、R06 海边阴天、R08 烛光夜室 |
| 古风妆造 | R05 老宅顶光、R07 林间漫射、R08 烛光夜室、R01 逆光黄昏 |

## 一次出多张时怎么配

**同一配方内换景别**（推荐，成片最像一组）：
特写 → 中近景 → 中景 → 全景，光线与场景完全不动，只换距离和姿势。

**跨配方**（适合一次试多个方向）：
选 2–3 个色调差异大的配方各出一张，当作选型用，不要当成一组作品发。
