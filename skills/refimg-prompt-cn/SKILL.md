# 多参考图人物一致性提示词

## 何时用这个技能

用户手里有参考图，想生成「同一个人、换场景 / 换衣服 / 换姿势」的照片。核心难点永远是三个：**脸会漂、衣服会被重新设计、比例会崩**。这个技能解决这三个。

不适用于：纯文生图（无参考图）、非人物题材、插画风格。

---

## 第一原则：参考图职责分离

所有参考图必须显式分工，并写明「不允许互相污染」。这是整套方法的地基。

| 编号 | 职责 | 只提取 | 一律不采纳 |
|---|---|---|---|
| A | 人物身份母图 | 脸、骨相 | 其余全部 |
| B | 场景母图 | 背景、空间结构、现场光 | 人物、构图 |
| C | 服装 / 妆造母图 | 衣服款式、面料、头饰、妆容 | **脸**、身材、姿势、背景、灯光、滤镜、水印与界面元素 |

提示词开头必须写清楚三者，并加一句优先级：

```
【优先级】
脸 → 只看 A；背景 → 只看 B；衣服与妆造 → 只看 C。三者互不干扰。
```

---

## 第二原则：脸被污染是最常见的失败

### 症状

生成结果的脸不是 A，而是 C 图里模特的脸，或者是 A 与 C 的混血。

### 根因

**视觉信息永远压过文字。**在提示词里写一百遍「不要采纳 C 的脸」都没用——只要 C 图里有一张完整、清晰、高信息量的脸，模型就会把它当成身份候选并做加权融合。C 图越好看、越清晰，污染越严重。

### 三种解法，按情况选

**解法一 · 裁头（首选，当 C 只需要提供衣服时）**
把 C 图的头部整个裁掉，只留脖子以下。零成本，零风险，效果最好。
淘宝汉服店铺的**平铺图**天然就没有脸，是最理想的 C 图来源。

**解法二 · 遮脸（当妆造和头饰长在头上，不能裁时）**
用柔边椭圆把五官区域（眼、鼻、嘴）盖成灰色块，保留发冠、头饰、耳饰、鬓发、服装。
代价：眼周的妆容细节（眼线、卧蚕装饰、泪痕、花钿）会一起丢失，必须用文字补描述。

**解法三 · 两步走（最稳，推荐用于复杂妆造）**
1. 第一步：正常用 C 生成。妆造会完美，脸是错的，不用管。
2. 第二步：把第一步的结果 + A 一起传，只做脸部替换。
优点：妆造与脸各自跑到最好，任何细节都不会丢。
换脸指令模板见 `references/prompt-template.md`。

### 工具：一键裁头 / 遮脸

`scripts/face_privacy_tool.py` 自动检测人脸并裁头或遮脸，不用每次手动估坐标。

```
python3 face_privacy_tool.py crophead 服装参考图.jpg      # 裁掉整个头，只留衣服
python3 face_privacy_tool.py maskface 妆造参考图.jpg      # 只把五官盖灰，保留发冠头饰
python3 face_privacy_tool.py detect 某张图.jpg            # 看看检测框准不准，不生成文件
```

自动检测失败或框不准时，用 `--bbox x,y,w,h` 手动指定。批量处理整个文件夹用 `--batch 输入夹 输出夹`。
`crophead` 对贴脸特写慎用——脸占满画面时默认裁切比例会把衣服也裁没，遇到这种就改用 `maskface`。
完整参数说明见脚本内 `--help` 或文件顶部的说明。

### 无论用哪种解法，都要带这一段

```
【脸部铁律】
脸是全图唯一不可改动的元素。妆容与造型只能覆盖在参考图 A 原有的五官结构之上，
不允许改变脸型宽窄、下颌线、下巴长度与尖度、眼睛形状与大小、眼距、眉眼间距、
鼻梁高度、鼻翼宽度、嘴巴大小、上下唇比例、人中长度、年龄感。
不要放大眼睛，不要削尖下巴，不要磨平颧骨，不要幼态娃娃脸。
造型与脸冲突时，一律以脸为准。
```

**关键洞察：**描述妆容越详细，模型越把脸当成可以重绘的对象。妆容段落要克制，只写「怎么画在这张脸上」，不要写「应该长成什么样」。

## 第三原则：提示词的顺序决定成败

模型对超长提示词会做压缩，**越靠后的段落权重越低**。所以：

**推荐顺序**

1. 参考图说明 + 优先级
2. 脸部铁律
3. 身材比例硬指标
4. **分镜 / 姿势 / 构图**（提前，这是最容易被稀释的部分）
5. 服装
6. 妆发
7. 场景与光线
8. 影调
9. 禁止清单

**反面教材：**把四个分镜全压在两千字提示词的末尾。结果就是四张图姿势雷同，「回眸」「坐姿」「全身」这些指令全部落空。

**长度：**控制在 800–1200 字。超过 1500 字开始明显掉指令。宁可拆成多次生成。

---

## 第四原则：否定式约束比正面描述有效

模型有强烈的默认倾向（古风→仙侠手游时装、街拍→影楼、人像→网红脸）。正面描述拉不回来，**明确的「不要」才能拉回来**。

每条提示词末尾都要有一份禁止清单。基础版：

```
【禁止】
AI塑料脸、游戏建模脸、放大眼睛、幼态娃娃脸、磨平颧骨、头身比失调、腿短、
俯拍压缩、广角畸变、擅自重新设计衣服、过度磨皮、塑料假发、超长假睫毛、
仙侠特效、光粒子、发光皮肤、漂浮无重力的衣袖、藏手断手、错误手指、
水印与界面元素、四宫格与任何形式的拼图。
```

按题材追加，见 `references/troubleshooting.md`。

## 第五原则：身材比例与镜头是可控的

「人显矮」几乎不是模型的错，是提示词没写机位。三条硬指标：

```
【身材比例硬指标】
腰封／腰线位于肋骨下缘的高腰位置，不要压在肚脐或胯部。
人物头身比不低于 1:7.5。高髻、发冠属于发型，不计入头部长度。
全身照：相机放低到膝盖高度做低机位，远景水平线落在人物膝盖附近；
使用等效 85mm 中长焦拉开距离，不要俯拍，不要广角贴近拍。
站姿一脚略前一脚略后，重心在后腿，不要双脚平行正面直立。
```

**诊断技巧：**看背景水平线落在人物身上的哪个高度。落在胸口 = 相机太高 = 腿被压缩。落在膝盖 = 正确。

## 第六原则：光线一致性决定「像不像真照片」

这是最容易被忽略、但最能提升真实感的一段：

```
【光线一致性（硬指标）】
人物必须自然接受参考图 B 现场的环境光与色温，
绝不能出现人物是暖黄棚拍光、背景是冷色户外光的抠图感。
头发边缘、半透明面料、毛绒、饰品都要真实受现场光影响。
```

## 只有人物图：氛围感创作

用户只上传一张人脸参考，说「生成好看的、有氛围感的照片」，其余全部由你设计。
这不是复刻任务，是**创作任务**——但脸依然要锁死。

### 三件事必须由你决定，不要反问用户

1. **配方**（光线 + 场景 + 色调 + 情绪）：从 `references/mood-recipes.md` 里按人物气质选，不是按好看选
2. **服装**：跟着配方走，写具体到材质与廓形，不要写「好看的衣服」
3. **她在做什么**：一个具体的动作，不是「摆姿势」

用户说「随便」时，选定一个配方直接给完整提示词，并说明你选了哪个、为什么适合这张脸。给两个方向让用户挑，比问三个问题有用。

### 氛围感的七条（详见 mood-recipes.md 开头）

光是第一位 → 不要正脸大头照 → 前景遮挡 → 环境要有呼吸 → 一个色温 → 保留不完美 → 让她在做一件具体的事。

**最容易被忽略的是第三条。**树叶、纱帘、花枝、玻璃、栏杆横穿画面，几乎是「像摄影作品」和「像自拍」的分界线。

### 只有一张人脸参考时，脸更容易漂

因为没有 C 图分散注意力，模型会把全部创作自由用在脸上。所以：

- 脸部铁律照常带，一个字不能少
- 追加一句：`画面中的脸必须来自参考图 A，不允许因为造型、光线或风格化而重新设计五官。`
- **不要写「精致美丽的东亚女性」这类形容词**。任何对脸的正面描述都是在邀请模型重画。只描述妆容怎么画在这张脸上。

### 一次出多张

同一配方内换景别最容易出成组的感觉：特写 → 中近景 → 中景 → 全景，光线与场景完全不动。
跨配方只适合一次试多个方向，不要当成一组作品。

完整模板见 `references/prompt-template.md` 的「氛围感创作」一节。

## 场景替换（把已有照片换个背景）

这是一类独立任务：人物已经拍好了，只想换背景。参考图配置变成两张——

- 参考图 1 = 待修改的照片，人物 / 妆造 / 姿势 / 构图的唯一来源
- 参考图 2 = 新背景，只提取空间结构与现场光

**唯一的难点是光，不是背景。**换背景失败十有八九不是背景画错了，而是人物还带着原场景的光。白天冷光的人贴进夜景，一眼就是抠图。

所以必须写一段【光线重打】，而不是只写新背景长什么样：

```
【光线重打】
这是从 [原光线条件] 换到 [新光线条件]，光线必须整体重做，不能保留原图的光。
人物由 [新的主光来源与方向] 照亮，[受光面描述]。
人物边缘——发丝、饰品、半透明衣料——必须自然接受新背景的环境光与反射光，
产生对应色温的轮廓光和环境色沾染。
绝对不能出现人物是 [原光线]、背景是 [新光线] 的抠图感。
```

**必须保持不变的清单要写得非常细。**只写「人物不变」不够，模型会顺手重绘妆容和头饰。逐项列出：脸的每一处骨相、妆容的浓度与位置、发型形状、头饰的种类数量位置、服装细节、姿势与手持物、构图裁切。

**常见翻车与补救**

| 症状 | 补救 |
|---|---|
| 人物像贴上去的 | 补【光线重打】段 |
| 人物太亮、浮在背景上 | 「降低补光强度，让脸部亮度只比环境高一到两档，肩膀外侧与手臂边缘允许落入暗部」 |
| 背景被整体提亮、失去夜感 | 「背景保持欠曝的暗调，不要为了看清而整体提亮」 |
| 原背景的标志性元素残留 | 在禁止清单里点名：「不要保留原图的 [具体元素]」 |
| 顺手改了妆容或头饰 | 把不变清单写得更细，逐项点名 |

完整模板见 `references/prompt-template.md` 的「场景替换」一节。

## 第七原则：多张之间的一致性

一次出多张时，模型会逐张漂移——头饰变多变少、发髻高度变化、妆容浓淡不一。

**写死不变项：**

```
四张是同一个人、同一天、同一场景、同一套妆造。
发髻高度与形状、头饰的种类数量与位置、妆容浓度、服装细节、腰带高度，
四张必须完全一致，只允许因视角产生正常变化。
```

**更强的做法：**第一张满意后，把它作为额外参考图传给后面几张：

```
参考图 D = 同组照片的连续性基准，头饰的种类数量位置、发髻形状、
妆容浓度、服装细节必须与之完全一致。
```

**批量出图的真相：**平台的「一次出 4 张」是同一条提示词跑 4 个随机种子，没法指定「第 1 张撩发、第 2 张插兜」。要精确控姿势就得分开跑；要一次出多张就把姿势写成开放式，从结果里挑。

## 工作流

1. 确认工具（ChatGPT 图像 / 即梦 / Nano Banana / Flux）与语言
2. 确认参考图配置：A 一定有；B、C 视需求
3. **检查 C 图有没有脸** → 有就裁 / 遮 / 走两步法
4. 按第三原则的顺序组装提示词
5. 出图后按 `references/troubleshooting.md` 逐项对照诊断
6. 用二次修改指令做局部修正，不要整条重跑

## 输出规范

- 提示词一律放在代码框里，方便复制
- 用户要求「完整版」时，把所有修正合并进一条完整提示词，不要给片段让用户自己拼
- 每条提示词自包含，可以直接粘贴使用
