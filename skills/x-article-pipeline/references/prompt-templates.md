# 提示词模板

## 统一风格描述（每张配图末尾都加）

默认三色是暖白、深墨蓝、朱红。换话题可以换三色，但一篇文章里保持同一组。

```
统一风格：暖白纸张背景带细微纤维质感，深墨蓝色线条，朱红色是唯一亮色，柔和的左上方自然光，阴影浅而长，像高端杂志内页或瑞士风格信息图，安静克制，低饱和，大量留白。画面中不要任何文字、字母或数字，不要科技元素，不要机器人、大脑、电路图案，不要发光效果，不要渐变。
```

## 配图的三种类型

- 静物摄影型：用真实物件表达比喻（作文纸和答题卡、煤块、铅笔）。适合开头和概念类段落
- 平面信息图型：用圆点、线条、刻度尺、分岔的流线表达机制（串行 vs 并行、门槛、分层漏斗）。适合讲原理的段落
- 底图型：卡片、进度条这类要放数字的，只让 AI 出底图，留出空白给后期加字

写法：先说比例和类型，再说画面里有什么、怎么排、哪个元素用亮色，最后接统一风格描述。

## 例：串行 vs 并行

```
横版 16:9 极简平面插画，上下两行对比。上面一行是十个深墨蓝色小圆点排成一条直线，圆点之间用细线依次连接，只有最左边三个是实心的，其余是空心，表现一个接一个慢慢生成。下面一行是同样十个圆点，全部同时是实心朱红色，用一条竖直细线齐刷刷对齐，表现一次同时完成。两行之间留出明显空白。（接统一风格描述）
```

## 封面模板（5:2，带标题词）

```
极简高级的编辑风格封面，横版 5:2 比例。
画面是一张暖白色纸张的正面特写，纸面有细微的纤维质感和极轻的起伏，像真实的高磅数艺术纸。
画面左侧三分之一处印着一个单词 "【词】"，拼写严格为【逐个字母说明大小写】，共【N】个字母。字体是高对比度的现代衬线体，类似 Didot 或 Canela，字重偏细，字号很大，约占画面高度的四成，颜色是深墨蓝色，像凸版印刷压进纸里，边缘有真实的油墨质感。
画面右侧是【呼应正文比喻的简洁图形，例如几行答题卡圆圈，其中一个涂成朱红色】，线条极细。
文字和图形之间保留大面积留白。
柔和的自然侧光从左上方照过来，纸面有很浅的阴影。
风格像高端杂志内页或设计工作室的品牌海报，安静、克制、精致。
配色只有暖白、深墨蓝、朱红三种颜色。
画面中只能出现 "【词】" 这一个词，不要其他任何文字、字母、数字或标志。不要发光效果，不要渐变，不要科技感元素，不要机器人、大脑、电路、代码图案。
```

封面备选方向：
- 瑞士海报风：米灰背景，粗重无衬线大字贴左下，右上一行细线圆环，其中一个实心亮色
- 纸面静物摄影：奶油色厚纸在亚麻桌面上，活字印刷的标题词，旁边放一件呼应主题的实物，50mm 镜头，胶片细颗粒

## 压 AI 味的补丁句

生成结果太光滑时，加在提示词末尾：

```
像用真实相机拍摄的，35mm 镜头，自然光，没有过度修饰。
```
