# 人物拍照姿势表情动作

## 何时用这个技能

用户已经有一张满意的人物照片，想要「同一个人、同一身衣服、同一个地方，换个表情或动作再来几张」。
适用于 ChatGPT 图像 / Nano Banana / 即梦 Seedream / Flux Kontext 等支持图生图的模型。

不适用于：换背景（那是场景替换）、换衣服（那要服装参考图）、只有人脸没有成图的氛围感创作。
这三种走 `refimg-prompt-cn`。

---

## 第一原则：这是延伸，不是创作

用户要的是「同一组照片里的第二张」，不是「一张新照片」。
所以提示词的任务描述必须一开头就定性：

```
本次不是重新创作，是在同一张照片的基础上做极小幅度的延伸。
```

**全图只有两个变量：表情、手。其余一律锁死。**

模型的默认倾向是「重新拍一张」——它会顺手换机位、改构图、重新调色、重画妆容。
把变量写清楚不够，必须把不变项逐项点名。

---

## 第二原则：不变清单要逐项点名

写「其余保持不变」等于没写。必须按六类逐项列出，照着原图看图说话：

| 类别 | 要点名的内容 |
|---|---|
| 脸 | 脸型宽窄、下颌线、下巴长度与尖度、眼型眼距、鼻梁鼻翼、唇形比例、人中长度、年龄感 |
| 发 | 分缝方式、刘海形状与落点、发卷形态、发尾长度、碎发走向与蓬松度 |
| 妆 | 眼线形状与上扬角度、卧蚕、眉形、底妆质感、唇色与唇面光泽——写「浓度与位置不变」 |
| 服 | 颜色、款式、领型、拼色、刺绣与印花、配饰、下装、项链耳饰 |
| 景 | 背景物件**逐个数出来**，写明「位置与数量不变，不增不减」 |
| 机位与光 | 相机高度、角度、焦段、景深、人物占画面比例、裁切范围、光的方向与色温 |

**背景这一项最容易翻车。**只写「背景不变」，模型会删掉墙上的海报、挪走椅子、换掉菜单板。
看着图把物件数出来写进去：吧台、陈列柜、菜单板、相框、海报、空调、窗户、桌椅。

---

## 第三原则：脸部铁律照常带

哪怕只是改表情，脸也会漂。必须带这一段：

```
【脸部铁律】
脸是全图唯一不可改动的元素。不允许改变脸型宽窄、下颌线、下巴长度与尖度、
眼睛形状与大小、眼距、眉眼间距、鼻梁高度、鼻翼宽度、嘴巴大小、
上下唇比例、人中长度、年龄感。
不要放大眼睛，不要削尖下巴，不要磨平颧骨，不要幼态娃娃脸，不要重新美化。
表情变化只能由面部肌肉带动，骨相与五官结构本身一动不动。
```

最后一句是关键：**把表情定义成肌肉位移，而不是重新画一张脸。**
没有这句，模型会把「微笑」理解成「换一张在笑的脸」。

---

## 完整提示词骨架

```
【参考图说明】
参考图 A = 唯一基准图。人物身份、脸、发型、妆容、服装、场景、光线、色调、
构图与裁切范围，全部以这张为准。本次不是重新创作，是同一张照片的极小幅度延伸。

【任务】
输出 N 张彼此独立的[竖/横]构图单图，与参考图 A 是同一个人、同一天、同一地点、
同一套衣服妆发、同一套光线。两张之间、以及两张与 A 之间，
只允许有表情与手部动作的差别。不要拼接，不要四宫格，不要放进同一张画布。

【脸部铁律】
[整段照抄上文]

【必须保持不变（逐项）】
发型：[看图写]
妆容：[看图写] 浓度与位置不变，不要加重也不要减淡。
服装：[看图写]
场景：[背景物件逐个数出来]，位置与数量全部不变，不增不减。
相机：机位高度、角度、焦段、景深、人物在画面中的占比与裁切范围完全一致。
光线：[方向与色温]，不变。

【本次唯一的变化】
第一张：[表情或动作]
第二张：[表情或动作]
动作幅度小，不要转身、不要换机位、不要重新构图。
手部若出现在画面中，五指结构完整、指节比例正常。

【影调】
与参考图 A 完全一致的[拍摄器材感]，原有的噪点与暗部质感保留，白平衡不变。
不要重新调色，不要加滤镜，不要过度锐化，不要磨皮，不要提亮。
真实照片，非插画非CG。

【禁止】
改变脸部五官、重新美化、改变妆容浓度、改变发型与刘海形状、改变衣服款式或颜色、
增减背景物件、改变机位或构图裁切、改变光线方向与色温、整体提亮或换色调、
AI塑料脸、放大眼睛、幼态娃娃脸、过度磨皮、发光皮肤、
错误手指、藏手断手、多出一只手、水印与界面元素、四宫格与任何形式的拼图。
```

段落顺序不要调。**【本次唯一的变化】必须放在不变清单之后、影调之前**——
压在最末尾会被稀释，导致两张姿势雷同。

---

## 姿势表情库

### 表情（幅度从小到大）

描述表情要写**肌肉怎么动**，不要写情绪形容词。「温柔的笑」模型不知道怎么画，
「嘴角提起两毫米、下眼睑推起形成卧蚕」它知道。

| 名称 | 写法 |
|---|---|
| 浅笑 | 嘴角向两侧轻轻提起约两毫米，不露齿；下眼睑被笑推起形成卧蚕，眼睛稍微眯窄，眉毛不动 |
| 抿唇 | 嘴唇从微张改为轻轻闭合并抿住，唇线略收，表情收敛 |
| 走神 | 睫毛垂下，视线落向侧下方，唇微松，焦点不在镜头上 |
| 将语 | 唇微启像刚要开口说话，眉梢略放松，下巴略抬 |
| 抬眼 | 头略低而眼睛抬起看向镜头，形成上挑的视线，表情不动 |
| 轻笑 | 嘴角上扬露出一点上齿，眼尾下压，鼻翼轻微上提 |

### 手部动作（按画面里实际有的东西选）

| 名称 | 写法 |
|---|---|
| 别发 | 指尖把脸侧的一缕头发轻轻拨到耳后，手腕放松、五指微分 |
| 触下颌 | 食指与中指虚虚地贴在下颌侧面，不用力、不压变形 |
| 扶领口 | 一只手轻轻捏住衣领边缘或领口的布料 |
| 扶肩 | 手搭在对侧的肩膀或上臂，手臂横过胸前 |
| 撑台面 | 小臂搭在身前的桌面／吧台上，重心随之偏向一侧 |
| 拎衣料 | 手指拎起身侧的裙摆或衣摆，身体微转 |
| 持物 | 手握住画面中已有的杯子／手机／包带，不要凭空新增道具 |
| 垂落 | 双手在身前自然交叠垂落，手指放松 |

**只用画面里已经有的东西。**凭空加一杯咖啡、一束花，就不再是同一组照片了。

### 身体（幅度最大，谨慎用）

偏头十度 / 肩线略斜 / 重心从一条腿换到另一条 / 上身微微前倾。
**不要写转身、起身、换座位**——那等于换机位，构图必崩。

---

## 配对原则：一静一动

出两张时最稳的组合：

- **第一张只改表情**，手臂与身体位置一个像素都不动
- **第二张加一个手部小动作**，头随手的方向偏一点，视线跟着走

这样两张之间有变化但明显是同一时刻连拍，成组感最好。

出四张时用递进：表情收敛 → 表情放开 → 手部动作 → 视线离开镜头。
**不要每张都换景别**——换景别就不是微调任务了，那是另一套提示词。

### 一个必须知道的现实

平台的「一次出 N 张」是同一条提示词跑 N 个随机种子，
**没法保证第 1 张按你写的分镜一、第 2 张按分镜二**。

两条路：
- 要精确控制每张 → 分开跑，每次只写一个动作
- 要一次出多张 → 把动作写成开放式（「表情与手部动作在小范围内自然变化」），从结果里挑

第一张满意后，把它当作额外参考图传给后面几张，一致性会明显更好。

## 翻车速查

| 症状 | 补救（局部修改，不要整条重跑） |
|---|---|
| 脸漂了 | `只修改脸部，把五官完全替换回参考图的样子，保持同样的眼距、眼型弧度、鼻梁高度、人中长度与唇形厚度，其余画面元素全部不变。` |
| 手指崩了 | `只修正手部，五指结构完整、指节比例正常、指甲形状自然，手的位置与画面其余部分全部不变。` |
| 构图被改了 | `保持与参考图完全相同的机位、焦段、人物占比与裁切范围，不要重新构图。` |
| 色调变了 | `恢复参考图原本的白平衡与影调，不要提亮，不要加滤镜，不要重新调色。` |
| 背景物件少了 | 在不变清单里把那个物件单独点名，重跑 |
| 两张不像同一时刻 | `两张的发型形状、碎发位置、妆容浓度、衣褶走向必须完全一致，只允许表情与手部不同。` |
| 动作幅度过大 | `动作幅度控制在极小范围，是一个不经意的小动作而不是摆拍。` |

---

## 工作流

1. 看图，把六类不变项逐项写出来（背景物件要数清楚）
2. 从姿势表情库里按画面条件挑两个，配成一静一动
3. 按骨架组装，变化段放在不变清单之后
4. 出图后对照速查表，用局部修改指令补，不要整条重跑

## 输出规范

- 提示词一律放代码框，方便复制
- 用户传图后，把方括号按画面实际内容填成具体描述，不要留占位符给用户自己拼
- 每条提示词自包含，可以直接粘贴使用
