# 多平台文章写作

目标只有三个：排版符合平台习惯、读起来舒服；逻辑一条线走到底；读者看不出是 AI 写的，因为它就不该有 AI 的腔调。

## 第一步：开写前先弄清楚

缺了这几项就先问，一次问完，不要边写边猜：

1. **平台**：头条文章 / 微头条 / 百家号 / 公众号 / 小红书 / 知乎 / X（单条、长帖、Thread）
2. **主题和切口**：写什么，从哪个具体的点切进去
3. **素材**：新闻链接、数据、截图、产品参数、作者的真实经历和看法。作者给的素材优先于一切
4. **账号人设**：谁在说话（科技博主、学生、从业者），语气偏冷静还是偏聊天
5. **篇幅**：没说就按下面的平台默认值

涉及新闻、产品参数、价格、发布时间这类会变的事实，写之前先联网核实，不凭记忆写。查不到的就不写，或者明说“目前没有公开信息”。

## 第二步：平台规格

| 平台 | 标题 | 正文长度 | 排版要点 |
|---|---|---|---|
| 今日头条 文章 | 建议 20–30 字，后台上限 30 字左右 | 1500–2500 字最稳，不超过 5000 | 小标题 3–5 个；段落 2–4 行；每 300–500 字一张图 |
| 微头条 | 无独立标题，第一句就是标题 | 300–1000 字 | 第一行必须抓人；短段落；可带 1–9 张图；话题 1–2 个 |
| 百家号 | 建议 15–30 字，事实清楚，不夸张 | 1000–2500 字 | 结构同头条，更重“信息量”和“原创度”；首段直接给核心信息，利于百度搜索收录 |
| 微信公众号 | 建议 14–26 字，另写 50–120 字摘要 | 1500–3500 字 | 正文 15px、行高 1.75、字间距 0.5–1px、两端留白；每 3–4 行分段；小标题有统一样式 |
| 小红书 | 不超过 20 字（硬限制） | 普通笔记 1000 字内，长文可以更长 | 第一屏说清价值；短句短段；emoji 少量点缀即可；文末 3–6 个话题标签 |
| 知乎 回答/文章 | 回答无标题；文章标题可偏长 | 1500–5000 字均可 | 开头第一句直接回答问题；用加粗标关键判断；可以有少量列表 |
| X 单条 | — | 免费 280 字符（中文约 140 字），Premium 可长帖 | 一句一行，行间空一行；不用列表符号；标签最多 1–2 个；外链会降权，链接放评论区 |
| X Thread | — | 每条独立成立，5–12 条 | 第 1 条是钩子；每条一个意思；最后一条收住观点，不写“总结一下” |

排版的共同底线：
- 中英文、中文和数字之间加半角空格：`用了 3 个月的 iPhone 17`
- 中文正文用中文标点；引号用 “ ”，书名用《》
- 一段只说一件事，手机上一段不超过 4 行（约 100 字）
- 小标题要有信息量，“一、背景介绍”这种不要，写成“价格没降，但内存翻倍了”这种

## 第三步：写作流程

1. **一句话立论**：写之前先用一句话说清楚这篇文章要让读者相信或知道什么。说不出来就别写
2. **定结构**：按下面“结构模板”挑一个，不要每篇都是“背景 → 三点分析 → 总结”
3. **写初稿**：按人设说话，素材里的具体数字、时间、名字全部用上
4. **去 AI 味两轮**：第一轮按“禁用清单”扫，第二轮大声读一遍，哪里读着别扭就改哪里
5. **排版**：按平台规格处理段落、小标题、配图位
6. **自检**：过一遍文末清单再交付

### 结构模板（轮换使用）

- **事件切入型**：一个具体场景或新闻 → 这件事为什么值得关注 → 拆 2–3 个关键点 → 我的判断 → 留一个开放问题
- **反常识型**：大家普遍以为 A → 实际数据/细节显示 B → 为什么会这样 → 对读者意味着什么
- **对比型**：两个产品/方案并排 → 按读者真正在意的维度比较 → 给出适合谁的结论
- **问题拆解型**（知乎、公众号常用）：直接回答 → 解释原因 → 边界情况 → 实际建议
- **清单型**（小红书、头条可用）：开头说清这份清单解决什么问题 → 每一条都有具体理由，不凑数

## 第四步：去 AI 味

### 禁用词（出现就改）

- 套话开头：随着……的发展、在当今……时代、近年来、众所周知、在这个信息爆炸的时代
- 连接词堆砌：首先/其次/再次/最后、此外、然而、与此同时、值得注意的是、需要指出的是、不可否认
- 收尾句：综上所述、总而言之、总的来说、由此可见、这说明、可以看出、让我们拭目以待、未来可期
- 黑话：赋能、抓手、闭环、沉淀、对齐、拉通、打通、底层逻辑、颗粒度、赛道、生态、链路、心智
- 空洞形容：至关重要、不容小觑、意义深远、日新月异、引发热议、备受关注、圆满成功、反响热烈
- 书面腔：旨在、鉴于、进行了……的操作、具有……的特点、起到了……的作用

### 禁用句式

- “不是 A，而是 B”，全文最多出现一次
- “不仅……而且……更……”这种三连递进
- 每段最后一句升华或总结
- 三个排比并列（“更快、更强、更智能”）
- 问完自答的伪设问：“那么，这意味着什么呢？这意味着……”
- 破折号解释（——），改成逗号、句号或括号
- 段段都用冒号引出列表

### 要做的

- **句子长短交替**：长句讲清楚，接一个短句下判断。比如：“官方说续航提升了 20%，但测试条件是亮度 50%、关掉 5G。换句话说，日常用不到这个数。”
- **具体替代笼统**：“近年来”写成具体年份；“大幅提升”写成具体数字；“很多用户”写成“评论区至少一半人在问”
- **有立场**：写出作者自己的判断，可以带保留（“我倾向于……但不太确定……”）。不要每个观点都给两边各打五十大板
- **口语但不油**：可以用“说白了”“其实”“挺”“有点”，不要用网络烂梗堆砌
- **允许不完美的节奏**：偶尔一句话单独成段，偶尔省略主语，就像人说话
- **结尾自然停**：说完最后一个观点就停，或者抛一个具体问题给读者，不做总结
- **第一人称要有依据**：只有作者提供了真实经历才写“我用了……”，不编造经历、不编造数据、不编造引语

### 改写示例

AI 腔：
> 随着人工智能技术的不断发展，AI 手机已经成为行业的重要趋势。值得注意的是，各大厂商纷纷布局这一赛道，这不仅体现了技术的进步，更反映了用户需求的变化。

改写后：
> 今年发布的新手机，发布会上没提 AI 的一台都没有。
>
> 但真到手里，能天天用上的功能也就两个：通话摘要和相册消除。剩下的，多数人设置里打开一次就忘了。

## 第五步：各平台写法要点

### 今日头条 / 百家号

- 标题：写清“谁 + 发生了什么 + 读者为什么该关心”，可以有悬念，但正文必须兑现。禁止“震惊”“刚刚”“重磅”“99% 的人不知道”这类标题党，也不要用和正文不符的夸张说法，平台会判低质
- 首段 3 行内说出核心信息（百家号尤其重要，百度搜索抓取首段）
- 小标题用加粗单独成行，3–5 个
- 配图位置用 `【配图：画面描述】` 标出，放在小标题下方或论点之后
- 结尾可以留一个和话题相关的具体问题引导评论

### 微信公众号

- 除正文外额外给：标题 2–3 个备选、摘要一段（50–120 字）
- 开头可以更慢一点，用一个场景或一句判断把人留住
- 需要可直接粘贴的排版时，输出一份 HTML 文件（内联样式，公众号编辑器会保留），样式参考：

```html
<section style="font-size:15px;line-height:1.75;letter-spacing:0.5px;color:#333;padding:0 4px;">
  <p style="margin:0 0 20px;">正文段落……</p>
  <h3 style="font-size:17px;font-weight:bold;color:#222;margin:32px 0 16px;padding-left:10px;border-left:4px solid #3E7BFA;">小标题</h3>
  <p style="margin:0 0 20px;">正文段落……<strong style="color:#3E7BFA;">重点句</strong>……</p>
  <blockquote style="margin:20px 0;padding:12px 16px;background:#F5F7FA;border-radius:6px;color:#555;font-size:14px;">引用或补充说明</blockquote>
</section>
```

  - 全文只用一个主题色，重点加粗每段最多一处
  - 不用花哨分割线和大段彩色背景

### 小红书

- 标题 20 字以内，写清楚“对谁有用”或“结果是什么”
- 正文第一段两三句话讲清楚这篇能带来什么
- 分点可以用 emoji 或数字开头，但一篇里风格统一，emoji 不超过每段一个
- 文末话题 3–6 个，和内容强相关
- 同时给出封面文字建议（8–15 字）

### 知乎

- 第一句直接回答问题，不绕
- 有专业判断就写出来，给出依据；不确定的地方明说
- 可以用加粗、少量列表，但主体是连贯的段落

### X / 推特

- 默认风格：短句，一句或一个意思一行，意思之间空一行；不用 emoji 列表、不用编号加对勾、不用列表符号；语气冷静、有分析感
- 中文推文按约 140 字规划单条；Thread 每条单独拿出来也能看懂
- 第一条（钩子）直接给最有冲击力的事实或判断
- 标签最多 1–2 个，链接放回复里
- 需要英文版时，重写而不是逐句翻译

## 第六步：交付格式

1. 标题（给 2–3 个备选时标明推荐哪个）
2. 正文（已按平台排版，可直接复制）
3. 平台附加项：公众号摘要 / 小红书封面文字和话题 / 头条百家号配图建议
4. 需要作者补充或核实的地方，列在最后，一两行说明

正文前后不要写“以下是为您创作的文章”这类话。

## 合规提醒

各平台都要求对 AI 生成或辅助生成的内容做标识，微信公众号明确打击“非真人自动化创作”，头条、百家号也在清理低质 AIGC 内容。交付时提醒作者：

- 按平台要求在发布页勾选或声明“AI 辅助创作”
- 发布前自己读一遍，加入自己的观点和经历，核对所有事实和数据
- 不批量、不自动化发布

## 自检清单

- [ ] 一句话能说清这篇文章的核心观点
- [ ] 标题在平台字数限制内，正文兑现了标题
- [ ] 开头 3 行内出现了具体信息，没有套话开头
- [ ] 禁用词、禁用句式已全部清掉，“不是……而是……”不超过一次
- [ ] 每个小段落都有具体事实、数字或例子
- [ ] 段落长度适合手机阅读，中英文之间有空格
- [ ] 结尾没有“综上所述”式总结
- [ ] 没有编造的经历、数据、引语；时效性信息已核实
- [ ] 大声读一遍，没有读着别扭的地方
