# 换脸提示词

## 术语（按用户的叫法，不要弄反）

- **母图** = 用户角色的定妆脸，身份基准，永远不变。这是要移植过去的那张脸。
- **场景图**（也叫目标图） = 用户想借用构图、姿势、服装、环境的那张图。它原本的脸要被丢弃。

用户默认先发母图、后发场景图。顺序不同时她会说明。

写进提示词时用「素材 1 = 母图（人脸身份来源）」「素材 2 = 场景图（目标画面）」，模型对编号的执行更稳。

任务是让"母图里的这个人本人出现在场景图的画面里"，不是生成相似的人，也不是两张脸融合。

## 三个核心失败模式

写提示词时按这三条对症下药，不要泛泛写"保持一致"。

### 失败一：融合（最常见）

模型把两张脸做平均，出来是第三个人。

场景图里原有的脸特征越强（浓妆、特殊唇色、独特脸型），融合越严重。

**解法：显式作废母图的脸。** 必须单独立一段，逐项点名不保留什么：

```
【素材 2 的脸必须完全丢弃】
素材 2 中原有人物的一切面部特征全部作废，不允许保留任何一项：
不保留它的眼型、眼睛大小、眼妆样式。
不保留它的唇色和唇形。
不保留它的鼻型、脸型、下颌线。
不保留它的肤色和妆容风格。
换脸后的这张脸，五官必须百分之百来自素材 1。
```

### 失败二：写实化漂移

模型倾向于把脸"修正"成符合真人解剖的样子，于是：

| 症状 | 原因 |
|---|---|
| 眼睛变小 | 按真人比例缩回去了 |
| 鼻子有了阴影 | 加了立体结构 |
| 出现雀斑、痣、毛孔 | 加了"真实皮肤细节" |
| 下颌变长变方 | 按正常骨骼修正了 |
| 眼线柔化晕开 | 锐利的图形被当成噪声抹平 |

滤镜脸（韩系、二次元感、大眼小脸）尤其容易被"修正"掉，因为它本身就偏离真人解剖。

**解法：正向锁定 + 反向禁止，两边都写。** 每一项都要给出可判断的描述，不能只写"保持一致"：

```
眼睛：眼睛的横向宽度占据脸部宽度的比例必须与素材 1 完全一致，不要缩小成常规写实比例。
鼻子：鼻梁和鼻翼几乎没有阴影，鼻子是接近平面的呈现，不要加立体投影和明暗结构。
皮肤：绝对不要添加雀斑、痣、斑点、毛孔、皮肤纹理或任何瑕疵。
整体画风：素材 1 是高度精致的韩系滤镜平面质感，不是写实摄影的立体面部，请保持这个画风，不要写实化。
```

眼线这类锐利图形要描述**形状**而不是"眼线"两个字：

```
上眼线是浓黑锐利的实线，紧贴睫毛根部，从眼头到眼尾逐渐加粗，末端明确地向斜上方拉长出一道尖锐的三角形眼尾。眼线边缘干净利落，不是柔和晕开的。
```

### 失败三：角度转换时借机重画

正脸参考图 → 侧脸母图，模型在重新投影的过程中会顺手改掉五官。

**解法：写清透视规则，同时锁死"角度变了但尺寸不变"。**

```
【角度转换】
素材 1 是正面平视，素材 2 是四分之三侧脸并向一侧倾斜。
把素材 1 的面部特征按素材 2 的头部朝向重新投影，符合三维透视：
靠近镜头一侧的脸颊更宽，远端脸颊被压缩，远端的眼睛略窄。
但即使在侧转角度下，眼睛的大小、眼线的形状、唇形、下巴的尖细度也必须与素材 1 保持一致，不要因为角度变化就把五官改小或改形。
不要把正面的脸原样平贴上去。
```

**选场景图的建议**：场景图的头部角度越接近母图，成功率越高。母图通常是正面，所以优先选微侧头的场景图，避开大幅侧脸和大俯仰。这条值得主动告诉用户。

## 场景图侧必须保留的清单

写全，漏掉的项模型就会改：

```
人物的姿势、身体角度、手部动作和手指形态。
发型、发量、头发的走向和每一缕头发的位置。
服装、配饰、首饰、指甲。
背景和环境中的一切元素。
画面的构图、裁切范围、景深和虚化程度。
整体的光线方向、色温、明暗关系和色调。
```

## 融合质量

```
【光线与融合】
面部的受光方向和明暗分布与素材 2 的环境光一致。
脸部肤色与素材 2 中人物的脖子、肩膀、手臂无缝衔接，不允许出现脸比身体白或色温不同的断层。
下颌与颈部、发际线与额头的交界自然过渡，看不出边缘。
面部的清晰度和噪点与素材 2 的整体画质一致，不要脸部特别清晰而身体偏软。
```

有贴图感时，追加一句指明场景图的具体受光方向（"面部左侧受光右侧在暗部"），比泛泛写"光线一致"有效。

## 完整模板

```
【参考图说明】
素材 1 = 母图，唯一的人脸身份来源。
素材 2 = 场景图，唯一的目标画面来源。

【任务】
把素材 1 中人物的面部身份，完整准确地替换到素材 2 中人物的脸部区域。
最终效果必须是「素材 1 的这个人，本人出现在素材 2 的场景里被拍下这张照片」。
不是生成一个长得相似的新人物，也不是把两张脸混合成第三张脸。

【素材 2 的脸必须完全丢弃 - 这一条最重要】
（逐项点名母图脸上要作废的特征）

【必须从素材 1 精确复制的部分】
眼睛：（大小占比、双眼皮形态、眼裂长度、间距）
眼妆：（眼线的形状而非名称，睫毛）
眉毛：（形状粗细颜色走向）
鼻子：（大小、鼻翼宽度、是否有立体阴影）
嘴唇：（厚度、唇形、唇色、质感）
脸型：（下颌线、下巴尖细度、脸的长短）
皮肤：（色调、干净程度、明确禁止瑕疵）
整体画风：（滤镜感还是写实感）

【必须从素材 2 保留、不允许改动的部分】
（见上方清单）

【角度转换】
（说明两图角度差，给透视规则，锁死尺寸不变）

【光线与融合】
（见上方段落）

【禁止事项】
不要改变素材 2 的任何构图和内容。
不要把眼睛画小。
不要柔化或改变眼线的形状。
不要添加雀斑、痣、毛孔或任何皮肤瑕疵。
不要给鼻子加阴影和立体结构。
不要改深或改变唇色。
不要拉长脸型或加宽下颌。
不要生成两张脸的混合体。
不要出现面部贴图感、边缘光晕、色差断层。

【输出】
只输出一张图，构图和尺寸与素材 2 完全相同。
```

## 工作方式

用户发来两张图时：

1. 先看两图的**角度差**，决定角度转换段怎么写；差距过大就建议换母图
2. 看场景图原有的脸有哪些**强特征**会污染结果，逐项写进作废清单
3. 看母图的脸有哪些**偏离真人解剖**的特征（大眼、无鼻影、极尖下巴、平面感），这些是最容易被"修正"掉的，正向反向都要锁
4. 直接给完整提示词，代码块，不要只给补丁片段

用户拿回结果后逐项对比诊断，说清楚是哪一项漂了、为什么漂。

## 经验记录

- 场景图原有脸的特征越强，融合污染越重，作废清单要写得越细
- 眼睛大小是像度的第一决定因素，永远单独列一条
- "不要磨皮"式的否定写法无效，但**"不要添加瑕疵"式的否定写法有效**——因为前者要求模型做加法，后者是让它别做加法
- 锐利的图形特征（眼线三角、尖下巴）要描述几何形状，只写名称会被平均化
- 角度差是成功率的最大变量，换一张角度接近的场景图比调提示词更省事
